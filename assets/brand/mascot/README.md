# Townmouse mascot originals

Both files are the owner's original PNGs, supplied 2026-11-15, copied here
byte-for-byte. They are 1254 × 1254 RGBA with their original transparency.
They are never cropped, recolored, or recompressed in this folder.

`townmouse-icon.svg` is generated from the bust: it embeds a 256 px PNG of the
same uncropped portrait inside an SVG wrapper (`public/icon.svg` and
`public/favicon.svg`). It preserves the owner's pixels; it is not an auto-traced
redrawing.

The optimized transparent WebP renditions live in `public/brand/`. Icons are
generated by `stewardship/make-icons.cjs`: the bust portrait is scaled
uncropped; the monoline cursor remains the 16/32 favicon for legibility.

The pattern follows the sister apps: RATBAG uses one uncropped square mascot in
a square art well, and FATCHIN uses the owner's original square PNG for its
navigation logo and icons.
